# VCF Converter

Browser-only converter for `.vcf` contact exports. It parses vCard files locally in the browser and exports contacts to `.xlsx` or `.csv`.

## Privacy

The app does not upload contact files to a server. File reading, parsing, preview, column ordering, and export all run in the browser.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
